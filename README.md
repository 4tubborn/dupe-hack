# Dupe Hack

Duplicate items like it's April Fools' Day!

## Features

### Obtaining

- Kill mobs or destroy entities with containers for a chance to obtain Dupe Hack.
- The Looting enchantment increases the drop chance when killing **mobs**.

- Or cheat one in using `/function dupe_hack:give` .

### Usage

- Hold Dupe Hack in your main hand and the item you want to duplicate in your offhand.
- Right-click to instantly duplicate the item!

### Config

- Use `/scoreboard players set #break_chance dupe_hack.config <chance>` to adjust the chance of Dupe Hack breaking when used.
- `<chance>` is a percentage from 0 to 100 (0 = never breaks, 100 = always breaks).
- Use `/function dupe_hack:config/reset` to reset the break chance to its default value.
